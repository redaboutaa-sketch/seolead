# Discovery documentation

Infrastructure and deployment discovery notes for this project are maintained
privately and are not published here.

They were removed from this repository — and from its history — on 2026-08-17,
because describing how a live server is put together is useful to exactly one
audience the project does not want to help.

Nothing was lost: the documents are intact in the owner's private operational
repository, each one carrying a note of where it used to live.

If you are the owner and looking for them, they are under
`docs/operations/seolead/` in the private platform repository.
